# 7セグ 000 Watcher

スマホのWebブラウザだけでカメラ映像を解析し、指定した3桁の7セグ表示が `000` になったら通知するGitHub Pages向けWebアプリです。

## 使い方

1. GitHub Pagesでこのリポジトリを公開します。
2. スマホで公開URLを開き、「カメラ開始」を押します。
3. 緑の認識枠を3桁の表示に合わせます。枠はドラッグで移動、四隅でサイズ変更できます。
4. 表示に合わせて「明るいセグメント / 暗いセグメント」と「しきい値」を調整します。
5. 「通知を許可」を押します。
6. `000` が指定回数連続で認識されると、通知・音・振動を実行します。

## GitHub Pagesの公開

Repository Settings → Pages → Build and deployment → Source を `Deploy from a branch` にし、既定ブランチの `/ (root)` を選択して Save してください。

通常、公開先は次の形式になります。

`https://<GitHubユーザー名>.github.io/<リポジトリ名>/`

## 認識方式

OCRライブラリや外部AI APIは使わず、認識枠を3分割して各桁の a〜g セグメント位置をサンプリングします。画像は端末内のCanvasで処理され、サーバーには送信しません。

## 調整のコツ

- 3桁が認識枠いっぱいに入るようにしてください。
- 数字以外のランプや小数点は、できるだけ枠の外にしてください。
- 明るく発光するLEDなら「明るいセグメント」、液晶など暗い線なら「暗いセグメント」を選びます。
- 誤認識する場合は、しきい値を少しずつ動かしてください。
- デバッグ表示では緑の矩形が点灯判定、赤が消灯判定です。

## 制約

スマホのブラウザがバックグラウンドになると、カメラやJavaScript処理が停止・制限される場合があります。監視中は原則としてWebアプリを前面表示したまま使用してください。
